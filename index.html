About

As a software engineer with several years of professional experience, I specialize in building practical applications that improve business operations, automate manual processes, and make complex data easier to manage. My experience spans full-stack development, backend services, database design, API integrations, cloud deployment, and AI-enabled workflow solutions across industries including distribution, retail pricing, and transaction processing.

I have built production applications using Python frameworks such as Django, Flask, and FastAPI alongside React and Angular frontends, with PostgreSQL and MySQL supporting data-intensive workflows. My work has included replacing spreadsheet-driven processes with centralized applications, designing REST APIs, implementing server-side validation and role-based access controls, and creating administrative tools that allow users to search, review, and update information without direct database access.

A major focus of my work has been translating real-world business processes into reliable software. I have designed systems that track transaction lifecycles, inventory, orders, promotional pricing, exception states, audit histories, and user activity. I work closely with operational teams to understand business rules, edge cases, and workflow challenges, then encode that knowledge into applications so critical processes are not dependent on spreadsheets or undocumented institutional knowledge.

I also have experience integrating internal and external APIs, building background processing workflows, implementing Redis caching, and deploying containerized applications with Docker and AWS services including EC2, S3, and RDS. I have used automated testing with Pytest, structured logging, monitoring, and GitHub Actions to improve reliability and catch issues before they affect production users.

More recently, I have incorporated AI into production workflows using OpenAI APIs and modern AI development tools. This has included document parsing, internal question-and-answer systems, workflow recommendations, and retrieval-augmented generation using embeddings and company process documentation. I use AI as a development accelerator while maintaining traditional engineering practices such as testing, code review, validation, and production monitoring.

My approach combines software engineering with systems thinking and operational analysis. I enjoy identifying where processes break down, understanding why they work the way they do, and designing technology that makes them more accurate, efficient, scalable, and easier for people to use.

Always learning. Always refining. Always looking for ways to make systems — and results — better.
